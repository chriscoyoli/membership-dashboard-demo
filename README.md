# Membership Health Dashboard (Demo)

A single-page dashboard for a golf association's membership data.

**[View the live demo](https://chriscoyoli.github.io/membership-dashboard/)**

All data is synthetic. No real organization or member is represented.

## Files

- `index.html`: the dashboard, with its styles, scripts, and data in one file
- `preview.jpg`: preview image for link sharing

Open `index.html` in a browser to run it.
